# Merritt

BC Transit's Merritt Regional Transit System (operator 37) is shown as a primary feed, with every route drawn and GTFS-realtime positions when the server polls them.

| Path | What |
|---|---|
| `region.json` | Region bounds, initial view, time zone, and primary feed |
| `config/feeds/bc-transit-merritt/` | Static and real-time feed settings |

What's still assumed is in [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md); when an answer is known, update the config and move the answer here with its source.
