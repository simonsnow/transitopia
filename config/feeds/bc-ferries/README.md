# BC Ferries

The Trillium Transit GTFS covers 23 routes and 96 stops from Haida Gwaii to the Gulf Islands. BC Ferries has no GTFS-realtime feed; vessel positions are matched from AIS and anchor the scheduled sailings. The configured AIS vessel list is incomplete, so unlisted sailings remain timetable estimates.

The GTFS states no license, and no BC Ferries terms for it were found. See [DATA-LICENSES.md](../../../DATA-LICENSES.md). AIS broadcasts are independently sourced and do not use BC Ferries' marks.

What's still assumed is in [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md); when one is answered, update the config and move the answer here with its source.
